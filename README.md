# JPCS – TSU Chapter | Frontend Challenge

A responsive, Formula 1-inspired landing page built for the Junior Philippine Computer Society (JPCS) – Tarlac State University Chapter frontend challenge.

## Features

- **F1 / Motorsport-Inspired Theme:** Custom typography, telemetry-styled UI elements, and interactive audio toggle.
- **Dynamic Content & Filtering:** Interactive category filters for chapter activities and events.
- **Scrollspy Navigation:** Smooth scrolling and active section indicator as you browse.
- **Responsive & Accessible:** Mobile-first layout powered by Bootstrap 5 with semantic HTML, ARIA attributes, and reduced motion support.

## Tech Stack

- **HTML5** – Semantic structure & accessibility
- **CSS3** – Custom styling & animations
- **JavaScript (ES6+)** – Interactive features and DOM manipulation
- **Bootstrap 5.3.8** – Responsive grid and utilities
